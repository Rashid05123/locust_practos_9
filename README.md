# Нагрузочное тестирование «ТоргЛайн» с помощью Locust

Практическая работа №9. Объект тестирования - REST API электронной торговой площадки «ТоргЛайн»
(курсовой проект: FastAPI + PostgreSQL + React, запускается в Docker).

## Файлы

- `locustfile.py` - сценарии нагрузки: 4 класса пользователей, 21 задание;
- `data.py` - генерация тестовых данных библиотекой Faker (русская локаль);
- `main.conf` - параметры основного прогона: 100 пользователей, +5 в секунду, 5 минут;
- `headless.conf` - короткий прогон в консоли без веб-интерфейса;
- `results/` - результаты: CSV со статистикой и HTML-отчеты основного прогона (`torgline_*`, `report.html`)
  и прогона до 400 пользователей (`stress_*`, `stress_report.html`).

## Сценарии

| Класс | Набор заданий | Задания | Доля пользователей |
|---|---|---|---|
| Guest | `CatalogTasks` (TaskSet) | каталог с фильтрами, поиск, карточка торгов, категории | 6/12 |
| Buyer | `BuyerTasks` (TaskSet) | свои заявки, свои сделки, наблюдение за торгами, **ставка (POST)** | 3/12 |
| Seller | `SellerTasks` (TaskSet) | свои лоты, карточка лота, категории, **новый лот (POST)** | 2/12 |
| Newcomer | `RegistrationFlow` (SequentialTaskSet) | категории, каталог ×5, **регистрация (POST)**, **вход (POST)**, профиль, изменение профиля (PUT), проверка профиля, карточки ×5, личный кабинет | 1/12 |

Вес GET-заданий - от 5 до 10, POST-заданий - 1. После теста `check_ratio` считает GET и POST
по статистике и завершает Locust с кодом 1, если GET меньше чем в 5 раз больше POST.

Перед тестом (`events.test_start`) через API создаются торги для ставок: продавец выставляет лот,
модератор одобряет его и назначает торги без задатка.

## Запуск

1. Отдельный экземпляр «ТоргЛайн» на порту 8091 (своя база, чтобы тестовые данные не попали в основную;
   лимит входов поднят, потому что все виртуальные пользователи заходят с одного адреса):

   ```powershell
   cd <папка torgline>
   $env:DB_PUBLISH="5441"; $env:WEB_PUBLISH="8091"; $env:LOGIN_RATE_LIMIT="100000"; $env:CORS_ORIGINS="http://localhost:8091"
   docker compose -p torgline_pr9 --profile full up -d
   ```

2. Locust:

   ```powershell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\locust --config main.conf       # основной прогон с веб-интерфейсом
   .venv\Scripts\locust --config headless.conf   # короткий прогон в консоли
   ```
